# CAB Checklist

## 布局与结构

- [ ] 第四栏（资源管理器）正确渲染在 RightPanel 右侧
- [ ] 第四栏宽度可在 200px ~ 50% 屏幕宽度之间拖拽调整
- [ ] 第四栏可折叠为左侧窄边条，点击后恢复
- [ ] 右侧面板不再包含「文件」tab，仅保留「工作台」和「对话内容」
- [ ] 第四栏折叠/展开、宽度状态跨会话持久化

## 文件树

- [ ] 点击「打开文件夹」弹出系统选择对话框
- [ ] 文件树正确递归渲染文件夹和文件
- [ ] 文件夹可展开/折叠
- [ ] 搜索框可过滤文件树（保留路径上下文）
- [ ] 右键菜单包含：新建文件、新建文件夹、重命名、删除、复制路径
- [ ] 拖拽文件/文件夹到另一个文件夹可移动
- [ ] 显示最近 5-10 个打开的文件夹历史

## 编辑器

- [ ] 点击文本文件在第四栏内打开编辑器
- [ ] 多文件以 tab 形式展示，可切换、关闭、pin
- [ ] MonacoEditor 支持编辑、语法高亮、行号、自动换行
- [ ] 主题自动跟随全局 light/dark 模式
- [ ] 支持完整 IDE 快捷键（Ctrl+S 保存、Ctrl+Z 撤销、Ctrl+F 搜索等）
- [ ] 未保存修改在 tab 上显示星号/圆点
- [ ] 关闭未保存 tab 时弹窗确认「保存 / 不保存 / 取消」
- [ ] 保存成功后内容正确写回磁盘
