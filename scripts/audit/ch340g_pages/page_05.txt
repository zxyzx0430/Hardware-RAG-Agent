CH340 have built-in FIFO buffer, and supports simplex, half- and full-duplex asynchronous 
communication. The UART interface supports 1 start bit, 5-8 data bits, 1 or 2 stop bits, and 
odd, even, space or mark parity bits. CH340 supports common baud rates: 50, 75, 
100, 110, 134.5, 150, 300, 600, 900, 1200, 1800, 2400, 3600, 4800, 9600, 14400, 19200, 
28800, 33600, 38400, 56000, 57600, 76800, 115200, 128000, 153600, 230400, 460800, 
921600, 1500000, 2000000 baud. Transmitter baud rate error is less than 0.3%, receiver baud 
rate error tolerance is at most 2%. 
The emulated COM port is fully functional. Compatible with most applications using the serial 
port, without the need of changing existing code. 
CH340 can be used to upgrade existing peripherals using serial ports into USB devices, or 
adding serial ports to a PC. With external level shifting hardware, interfaces including RS232, 
RS422 and RS485 can be provided. 
By adding infrared adapters, CH340 can be used to implement USB to SIR adapter, allowing a 
PC to communicate with IrDA peripheral.
