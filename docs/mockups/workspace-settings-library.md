# 设置与资料库交互原型

打开同目录的 `workspace-settings-library.html` 即可使用。文件包含全部样式、脚本和 SVG 图标，无需启动项目或连接网络。

本原型基于 2026-11-11 当前工作区源码整理，基线提交为 `39fbd8c5`，同时核对了尚未提交的 Token 统计界面改动。它没有修改 React 页面、共享接口或后端。

## 信息架构

| 左侧分组 | 右侧页面 | 对应现有组件 |
| --- | --- | --- |
| 资料空间 | 知识库、收藏夹 | `KnowledgePanel`、`KbCollectionManager`、`BookmarkPanel` |
| 模型与上下文 | 模型与服务、检索与分块、提示词与偏好、记忆中心 | `SettingsPage`、`RagSettingsPanel`、`LongTermMemoryEditor`、`MemoryHubPanel` |
| Agent 能力 | 工具与权限、Skills、MCP 服务 | `SettingsPage`、`PolicyBar`、`SkillsManager`、`MCPManager` |
| 偏好与运行 | 外观与语言、用量统计、运行日志、工具审计、关于 | `SettingsPage`、`TokenUsagePanel`、`StatsPanel`、`AuditLogPanel` |

页面右上角的“功能对照”列出每项现有功能在新布局中的位置。

## 保留的交互入口

- 模型：服务商增删改、密钥显示切换、连接验证的不同错误状态、模型列表、按服务商和用途选择模型、自定义模型名、会话上下文窗口、首次设置码，以及搜索和图像工具的独立配置。
- RAG：Temperature、Top K、输出上限、相关性阈值、Embedding 和 Agent 分块默认模型、端点、密钥、模型列表与上下文窗口。
- 记忆：系统提示词、手动长期偏好、清空与显式保存；工作快照、条目过滤和增改删、提案审批、硬件档案及结构化字段。
- Agent：工具开关、四种权限模式；标准 Skill 的创建、查看、编辑、文件入口、附加资源、兼容状态、启用前检查、删除、GitHub 候选预览与安装范围；MCP 的 JSON 配置校验、服务启停、工具列表与删除。
- 运行：主题、语言入口、字号、按日期和模型统计、折线/柱状图、输入/未缓存输入/输出/总量/缓存/命中率、会话概况、日志过滤/复制/清空与审计过滤/详情。
- 收藏：新建、重命名、删除收藏夹，收藏与移动条目、取消收藏、原对话定位目标。
- 知识库：新建、重命名、删除和启停；独立模型与分块配置；导入导出；文档选择和拖放上传、三种分块方式、启停、索引状态、删除、分块正文及页码/index，聊天检索范围。

## 建议新增

界面中的虚线“建议功能”标签区分新增设想：收藏内容搜索、标签、排序与视图切换；知识库搜索、索引状态筛选、本地检索试验。删除收藏夹时将条目移入默认夹，避免收藏遗失。

## 演示边界

- 所有样例均为虚构数据，没有读取真实配置、密钥、聊天、知识库或设备。
- 连接验证、索引、MCP 启停、GitHub 预览都是明确标注的模拟。检索测试仅匹配内置示例文本。
- 上传只读取文件名和大小，不读取正文、不上传文件；导出的是原型 JSON 清单，导入只接受本原型的清单格式，不等同于真实知识库备份。
- “原对话定位”和“打开 Skill 文件”展示目标状态，正式产品接线时调用现有会话/编辑器能力。
- 示例配置、收藏和资料目录使用独立 localStorage 键 `hwrag-layout-prototype-20261111-v1`。API Key 和用户输入的 MCP 环境变量仅留在页面内存，不写入此存储。
- 语言设置提供导航与外观页的英语预览；其余内容以中文展示。
- 可在“关于”中恢复初始演示数据。真实系统的 MCP 配置仍是进程内存，原型的持久化不代表真实后端行为改变。

图标使用 Lucide（ISC 许可），通过 Iconify 获取并内嵌。原型可离线打开。
