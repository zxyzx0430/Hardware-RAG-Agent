P0–P7 开发路线速览

核心底座 P0 → P1 → P2；P3 / P4 / P5 可在基础契约稳定后分线推进。

P0 · 契约

统一运行事实模型

Run/Event、调用 ID、错误、副作用和证据定位，让一次执行可还原。

P1 · 可靠性

持久恢复与中断处理

Session / Run / Checkpoint / Approval 可恢复，取消、重试和上下文保留有一致规则。

P2 · 用户控制

计划与变更交付

Plan → ChangeSet / Diff → Review → Apply → Verify → Undo。

P3 · 生态

原生 Skills 与工具扩展

Skills、MCP、Hooks、Plugins 的导入、权限、调用和更新可追溯。

P4 · 规模

隔离并行与质量评估

Worktree、Subagent、Trace、Eval 和结果集成形成协作闭环。

P5 · 专业深度

来源证据、代码与硬件验收

RAG 引用可定位，代码验证和真实设备结果可区分、可回流。

P6 · 新运行形态

Browser、Remote 与后台任务

异步执行、人工接管、通知、交付和取消使用统一 Run。

P7 · 最后实施

OS Sandbox 执行隔离

先有可替换 Executor 与 Policy 契约，最后启用 OS 级实际隔离。
