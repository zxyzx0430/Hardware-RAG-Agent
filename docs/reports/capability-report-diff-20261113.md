# 能力报告 HTML 差异（2026-11-13）

对比对象：`HEAD` 中的版本 vs 当前工作区版本。

## 结论

这是**增量改版**，不是覆盖删除。原报告主体、P0–P7 路线图和能力域页面都保留；新增了一个“用户体验 · 完整链路”页面，并把首页默认打开项切到该页。

## 新增

- 导航第一项：`用户体验 · 完整链路`（`journey`）。
- 8 个流程步骤：
  1. 第一次打开
  2. 附上资料
  3. 发出问题
  4. 查资料与委派
  5. 核对依据
  6. 确认执行
  7. 拿到结果
  8. 刷新、停止与继续
- “先交付哪三项”：保护用户输入、让一次修改可核对、对话内派发。
- “对话内派发 · 交互示例”：一个可点击的演示，展示主对话派发、侧栏子任务、模型/思考强度选择和结果回读。
- 新增样式：`.ux-grid`、`.ux-step`、`.ux-nav`。

## 变化

- `overview` 从 `page active` 改为 `page`，导航名称从“总览”改为“架构对标总览”。
- `journey` 成为默认激活页。
- 原“PRODUCT QUEUE · 前 7 项打磨顺序”改为“历史对标顺序”，原顺序内容保留。
- 文件从约 105 KB 增到约 112 KB，新增内容约 6 KB。

## 未变

- `roadmap`（P0–P7）页面保留。
- 所有能力域页面和原报告的历史对标内容保留。
- 原 P0–P7 路线图的条目和验收标准没有被删除。

## 判断

这份改动是另一条 UX 走查线写的，和这次 P2 收敛不冲突。内容本身有参考价值，但它不属于 P2 代码改动；如果保留，建议提交时和 P2 分开。
